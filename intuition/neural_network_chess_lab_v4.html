Teaching idea: the chessboard itself is not fed directly into this tiny network. Instead, the page first turns a candidate move into five understandable features. Those numbers pass through nn.Linear layers. A real chess model might learn directly from board encodings, use many more features, or use convolutional/transformer architectures. This simplified version makes every calculation visible.
